Four things I have built

All the code is public. The numbers are measured on held-out data, not estimated.

quantlab

Python, pandas, NumPy

Source

A backtesting and research engine for equities, crypto, and prediction markets. Every signal fills on the next bar, so a strategy cannot trade on information it would not have had at the time. Fees and slippage are charged on turnover, and every result is scored against simply holding the asset — a strategy that cannot beat holding is not a strategy.

Seven strategies sit behind one interface, and a registry discovers new ones automatically, so adding a strategy requires no change to the engine. Anchored walk-forward validation reports in-sample against out-of-sample Sharpe for each fold, which is the quickest way to see that a parameter set was fitted rather than found.

Banking Transactions API

Java 21, Spring Boot 3, PostgreSQL

Source

A core banking service: accounts, deposits and withdrawals that reject overdrafts, and transfers that either commit on both legs or roll back entirely.

Concurrent transfers take row locks in ascending account-id order, which rules out both double-spend and deadlock. Every balance movement writes an immutable ledger row carrying the resulting balance. 19 JUnit and MockMvc tests cover the service rules and the HTTP error contract, and run in GitHub Actions on every push.

Job-Opening Monitor

Node.js, TypeScript, Supabase

Source

A scheduled pipeline that reads around 5,000 postings per run from three unrelated hiring APIs — Workday, Greenhouse, and Lever — and normalizes them behind one adapter layer. Fetches run with bounded concurrency and no runtime dependencies.

A Postgres state table makes re-runs idempotent, so nothing ever alerts twice. It runs on a GitHub Actions schedule and sends matches to Telegram and email. 32 Vitest tests cover the matching and classification logic.

Credit Card Default Risk

Python, SQL, XGBoost, SHAP, Tableau

Source Dashboard

Portfolio risk analysis across 30,000 credit card customers. Five SQL analyses using window functions and CTEs, then logistic regression against XGBoost, reaching 0.777 AUC on a held-out set, with SHAP attributing each prediction to its features. The riskiest decile contains 31% of all defaults, a 3.1x lift over the base rate.

A grounded language-model layer drafts the weekly risk memo from the query output rather than from recall, so every sentence traces back to a number in the data.

What didn't work

I went looking for a strategy returning 50% a year. Three of the four routes I tried died the moment they met data they had not been fitted on. Keeping that record is more useful than deleting it.

Route Fitted on past data Held-out result Verdict
Weekly altcoin rotation 77–132% a year −3% a year from 2024 Dead
One-hour Donchian breakout Sharpe 4.36 Sharpe −0.89 Dead
4x leverage on the survivor — 11.2% a year at −64% drawdown Dead
Volatility-targeted momentum — Sharpe 1.05 at −16.4% drawdown Kept

The honest way to raise returns is not a cleverer signal. It is either accepting the roughly 1-to-1.5 return-to-drawdown arithmetic of trend following, or finding a structural mispricing and then being strict about whether the sample supports the claim. A study of Polymarket favourites looked promising at sixteen wins from sixteen, but the 95% lower bound on that record is about 81%, which is not yet above the average entry price. It needs roughly a hundred samples before it means anything, so it stays unproven rather than becoming a headline.

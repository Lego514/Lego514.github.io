# Lego514.github.io

Personal site for Yi-Lei (Ray) Li — https://lego514.github.io

Static HTML and CSS, no build step. Two external requests: Google Fonts
(Archivo, IBM Plex Mono) and a lazy-loaded Tableau Public embed.

The hero chart is a real walk-forward out-of-sample equity curve, extracted
from [quantlab](https://github.com/Lego514/quantlab) and drawn as an inline
SVG path. To refresh it after new market data, re-run the walk-forward and
regenerate the path — the numbers in the caption move, and they should.
